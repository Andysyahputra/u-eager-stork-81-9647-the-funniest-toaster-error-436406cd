One toaster error message of at most 120 characters, written for the [make.fun](https://make.fun/c/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty "The Funniest Toaster Error Message".

The program writes the error message to `/output/entry.txt`:

> ERROR 06: No bread detected. I toasted the air anyway. It turned out better than your last three slices.

Run it with Node 22+:

```sh
node main.ts
```
